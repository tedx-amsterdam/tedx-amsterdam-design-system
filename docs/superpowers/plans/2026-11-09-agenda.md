# Agenda Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An `Agenda` component in the design system, and the same agenda on `/after-growth` in Webflow, filled from a new CMS collection.

**Architecture:** A server React component renders an ordered list from an `items` array, styled with tokens only. Webflow mirrors it: a CMS collection "Agenda items" with a reference to "Upcoming events", a Collection List filtered on that event, and classes that use the "TEDx DS" variables with the same values as the tokens.

**Tech Stack:** React 18, TypeScript, CSS Modules, Vitest + Testing Library + axe, Storybook; Webflow MCP (data tools) and the Designer through Claude in Chrome.

**Spec:** `docs/superpowers/specs/2026-11-09-agenda-design.md`

## Global Constraints

- Tokens only in `Agenda.module.css`: semantic colours (`--text-accent`, `--text-primary`, `--text-secondary`, `--border-hairline`), spacing tokens, composite type tokens. `tests/styles.test.ts` must pass.
- Class names: `.root`, `.item`, `.time`, `.content`, `.title`, `.description`, `.label`.
- Named export only; `export type AgendaProps`; `cn()` for classes; `className` and `...rest` go to the `<ol>`.
- No `'use client'`.
- Examples and stories carry no edition's theme, tagline or year.
- Commits: English, conventional prefixes, atomic, ending with the Co-Authored-By line.
- Webflow: nothing is published without the user's explicit yes in chat.
- No JSON-LD for the agenda (spec, "Structured data").

## Review Focus

- **A time that is not `HH:MM`** ("2pm", "Afternoon"): the text shows, `datetime` is absent. Test in Task 1.
- **An item with neither description nor label:** no empty `<p>` or empty `Tag`. Test in Task 1.
- **An empty `items` array:** renders an empty `<ol>` without crashing; in Webflow the section hides when the list is empty. Test in Task 1; check in Task 5.
- **A long title or label at 390px:** wraps, no horizontal scroll. Check in Storybook in Task 2.
- **A CMS time without a leading zero** ("9:00" sorts after "18:30"): the Time field's help text asks for one. Set in Task 3.

```tsx
const items = [
  { time: '14:00', title: 'Doors open' },
  { time: '15:00', title: 'Talks start', description: 'The first five talks', label: 'No entry after start' },
];

it('renders one list item per entry, in order', () => {
  render(<Agenda items={items} />);
  const rows = within(screen.getByRole('list')).getAllByRole('listitem');
  expect(rows).toHaveLength(2);
  expect(rows[0]).toHaveTextContent('Doors open');
});
it('uses h3 for titles by default and headingLevel when given', () => {
  const { rerender } = render(<Agenda items={items} />);
  expect(screen.getByRole('heading', { level: 3, name: 'Doors open' })).toBeInTheDocument();
  rerender(<Agenda items={items} headingLevel={4} />);
  expect(screen.getByRole('heading', { level: 4, name: 'Doors open' })).toBeInTheDocument();
});
it('renders description and label only when given', () => {
  render(<Agenda items={items} />);
  const [first, second] = within(screen.getByRole('list')).getAllByRole('listitem');
  expect(first.querySelector('p')).toBeNull();
  expect(first).not.toHaveTextContent('No entry after start');
  expect(second).toHaveTextContent('The first five talks');
  expect(second).toHaveTextContent('No entry after start');
});
it('sets datetime for HH:MM times only', () => {
  render(<Agenda items={[{ time: '09:30', title: 'A' }, { time: '2pm', title: 'B' }]} />);
  expect(screen.getByText('09:30')).toHaveAttribute('datetime', '09:30');
  expect(screen.getByText('2pm')).not.toHaveAttribute('datetime');
});
it('renders an empty list without items', () => {
  render(<Agenda items={[]} />);
  expect(screen.getByRole('list')).toBeEmptyDOMElement();
});
```

- [ ] **Step 4: Write `Agenda.module.css`**

- `.title`: `font: var(--text-h3)`, `text-transform: uppercase`, `letter-spacing: var(--ls-display)`, colour `var(--text-primary)`, margin 0.
- `.description`: `font: var(--text-body)`, colour `var(--text-secondary)`, margin `var(--space-2) 0 0`.
- `.content`: `min-width: 0`, so long words wrap.
- Below 768px: `.time` and `.title` use `font-size: var(--fs-h3-m)`.
