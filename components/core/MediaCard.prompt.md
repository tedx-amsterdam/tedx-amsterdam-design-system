Image-led blog / event card: corner category label, UPPERCASE title, muted description, dated meta.

```jsx
<MediaCard
  image="assets/photo-audience.jpg"
  category="News"
  title="The power of ideas: 5 talks that changed Amsterdam"
  description="The power of ideas: 5 talks that changed Amsterdam"
  date="24 Jun 2025"
  href="/blog/power-of-ideas"
/>
```

Falls back to the red→orange tile gradient when `image` is omitted. Set `ratio` (e.g. `"1 / 1"`) per grid.
