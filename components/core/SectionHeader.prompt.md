The repeating section intro block: red eyebrow + bold heading + description + optional arrow link.

```jsx
<SectionHeader
  eyebrow="Speakers"
  title="Our Speakers"
  description="TEDxAmsterdam invites speakers to inspire with powerful stories."
  link="Check out our past Speakers"
  linkHref="/speakers"
/>
```

`align="center"` for centered hero intros (e.g. "Be the First to Get Tickets").
